# Showroom sitesi

1. GitHub'da YENİ bir repo aç (örn. `showroom`), bu klasörün içindekileri yükle (klasörün kendisini değil, içindekileri).
2. Settings → Pages → Branch: main / (root) → Save.
3. Kendi bilgilerini `products.js` dosyasında değiştir (marka adı, slogan, ürün adları).
4. Fotoğrafları `images` klasörüne yükle, `products.js` içinde `gorsel: 'images/dosya-adi.jpg'` olarak yaz.
