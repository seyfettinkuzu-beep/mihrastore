GitHub bağlantısı Bağlı değil

Bağlantı kurulunca Kaydet butonu değişiklikleri (yeni fotoğraflar dahil) doğrudan sitene yükler; site 1–2 dakika içinde güncellenir. Bağlantı olmadan da düzenleme yapabilirsin; o zaman Kaydet, yüklemen gereken dosyaları bilgisayarına indirir.

Token nasıl alınır? (bir kerelik, 2 dakika)
  1. GitHub'da sağ üstteki profil resmine tıkla → Settings.
  2. Sol menünün en altında Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: mihra-admin. Expiration: istediğin süre (ör. 1 yıl).
  4. Repository access: Only select repositories → sitenin reposunu seç.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Generate token'a bas, çıkan github_pat_… ile başlayan kodu kopyalayıp yukarıdaki Token kutusuna yapıştır.

Token yalnızca bu tarayıcıda saklanır, başka hiçbir yere gönderilmez (sadece GitHub'a). Ortak kullanılan bir bilgisayardaysan "Bu cihazda hatırla" işaretini kaldır; tarayıcıyı kapatınca silinir. Token'ı kimseyle paylaşma.
